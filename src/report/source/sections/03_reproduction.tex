\section*{Scope}
Use the authors' implementation, with pretrained models where available, on a small, fixed set of held-out scenes from V2X-Sim~\cite{li2022v2xsim}, a vehicle-to-everything (V2X) simulation dataset.
Assume \textbf{perfect communication settings}: synchronized observations, accurate vehicle poses, and communication without delay or packet loss.
Baseline models may be trained when needed to reproduce the reference comparisons.
Developing new methods is outside the scope.
Vehicles will be simulated as cooperating agents on one computer.
