# Institutional logos

The final report cover uses the UNICAMP and Instituto de Computação logos
already present in the author's EQM document. The PDF assets and original
IC logo style were copied unchanged on November 9, 2026. Their checksums
identify the exact bundled files.

| Asset | SHA-256 |
| --- | --- |
| `logo-unicamp.pdf` | `0448d9f88d55826816b511cf19fa1958994c44b575a64169548142e268dd07e6` |
| `logo-ic-unicamp.pdf` | `5164cf6db94def1c178500c74b269b58fc0e10b2689d2461f48131aa9efe71c7` |
| `logo-ic-unicamp.sty` | `f28849b0514fbb20acf20de58ad8dbc90f2dff4267eebb9bc806a5e090976b56` |

Both PDFs come from `src/eqm/source/assets/logos/`.
`logo-ic-unicamp.sty` comes from `src/eqm/source/styles/` and preserves the
EQM's original bold, spaced institute lettering and symbol proportions through
`LogoIcUnicampWithName`. The cover uses the EQM header's original 2.2 cm
UNICAMP width, 1.11 IC scale, and vertical alignment offsets.

Both logos retain their institutional ownership. Local copies let the report
build without an EQM checkout.
