# Appendix E generation example

This directory archives the single generation example shown in the final
presentation's Appendix E:

- `first-prompt.txt`: the tested conversational reconstruction.
- `submitted-first-prompt.txt`: the exact submitted prompt, including shared context.
- `first-prompt.generated.tex`: the typeset prompt included by the slides.
- `layout-preservation-initial.png`: that generation's unedited output.
- `generation.json`: date, generation context, and image/baseline hashes.

The prompt is a tested reconstruction, not recovered historical chat wording.
The baseline was not supplied as a reference to the generator. The original
slide-4 image, `../lidar-cooperation-v2.png`, remains the presentation's main
illustration. These archived assets require no generation service to build.
